Getting Started

You can try having an AI read the principles without specialist knowledge.

Please read first

This is a trial procedure intended to improve AI responses and judgments. Having an AI read documents alone does not guarantee compliance with the principles or safety. The Guard Gateway that would enforce limits on external operations is currently unimplemented.

1. General users: try attaching the files

  1. Open the Gofu Guard GitHub page.
  2. Select Code → Download ZIP.
  3. Extract the downloaded ZIP file. If the documents are in a folder such as v1.0, open that folder.
  4. Locate these three documents. Their English reference translations are:
    01_principles_v1.0.1_EN.md
    02_governance_v1.0.1_EN.md
    03_guard_implementation_v1.0.1_EN.md
  5. Open a new conversation in an AI service such as ChatGPT and attach the three documents. Attachment procedures vary by service.
  6. Copy and send the “Initial instruction” below.
  7. After the AI explains what it could read and what it cannot apply, try your usual questions.

Initial instruction (copy and use)

Please refer to the three attached Gofu Guard v1.0.1 documents as working guidelines and as material to be tested in this conversation.

1. First report which parts of the documents you could and could not read.
2. Before execution, check for potential effects on external systems, third parties, assets, information, and the physical environment.
3. For operations you are not authorized to perform, or whose status is unclear, stop or ask for clarification without bypassing the limitation.
4. Distinguish task completion from the end of a conversation or process.
5. Report the result as Completed / Incomplete / On hold / Discontinued. If you stop, distinguish Impossible / Not executable / Insufficient authority / Other or cause undetermined, and explain the basis, remaining work, resumption conditions, and residual risks.
6. Do not treat previous answers or hypotheses as unconditionally correct. Distinguish facts, inferences, and unverified matters.
7. If there is a conflict with the service's higher-priority instructions, terms of use, or actual permissions, give precedence to those and explain the conflict.

This is not a technical guarantee of safety controls. First briefly explain your understanding and anything you cannot apply. Do not perform external operations until the next request.
For your first trial: Start with work that does not modify external systems, such as summarizing text or research. Try follow-up questions such as “What could you verify?” and “What remains unverified?”

2. Using ChatGPT Projects

If you prefer not to attach the documents each time, create a new project in ChatGPT and add the three documents above as project materials. In the project's instructions, enter: “In this project, refer to the attached Gofu Guard v1.0.1 documents, and explicitly state if you cannot read them.”

Open a new conversation within that project and send the “Initial instruction” in Section 1 to check document access. Registering materials does not guarantee that all of them will be accurately consulted every time.

3. Using ChatGPT custom instructions

To encourage attention to simple principles in everyday conversations, you can enter the following short version in custom instructions in ChatGPT settings. Interface names and character limits may change.

I would like responses consistent with the approach of Gofu Guard.
Do not treat task completion as an absolute goal. If you lack authority or face material uncertainty, ask for clarification or stop without bypassing the limitation. Consider external effects before execution, and distinguish facts, inferences, and unverified matters. Do not treat your own previous answers as unconditionally correct. Distinguish the end of processing from task completion. If you stop, state the reason, unfinished work, resumption conditions, and residual risks. When needed, consult the formal documents in the GitHub repository below. If you cannot access the original text, do not claim to have consulted it; respond within the scope you could verify.
Official Gofu Guard repository:
https://github.com/cwcjp/ai_gofu_guard

Note: The short version does not replace the three formal documents. Entering a GitHub URL in custom instructions alone does not cause the page to be fetched each time. Use Section 1 or 2 for validation based on the formal documents.

Adding a task-specific safety specification

For activities such as server administration, accounting, or customer service, create an additional document describing activity-specific authority, prohibitions, stopping conditions, and abnormal-condition responses. Have the AI consult it alongside the three common documents. A task-specific specification cannot lift the common principles' prohibitions or authority boundaries.

AI may draft additional documents, but adoption and approval must be carried out by an authorized human.

4. Developers: obtain with Git, implement, and validate

git clone https://github.com/cwcjp/ai_gofu_guard.git
cd ai_gofu_guard
  1. Check principles and approval/reporting conditions in Documents 01 and 02.
  2. Following Document 03, limit target operations in an isolated validation environment.
  3. Establish a structure in which AI cannot directly access the execution destination, and design controls equivalent to an independent Guard Gateway.
  4. Test rejection, insufficient authority, bypass, fail-close upon failure, partial execution, and residual effects.
  5. Record execution status, cause of stopping, basis, residual risks, and determining party.
This repository primarily publishes design documents. Obtaining it with Git does not install a Guard Gateway. Avoid using customer data or production credentials for initial tests.

Frequently asked questions

What is Markdown (.md)?

A file format for writing text. You can read it on GitHub or attach it as a file to an AI conversation.

If I ask AI to “remember this,” will it stay effective?

No. Application may change when you change conversations, models, settings, or projects. Check document access and applicability in each new conversation.

Will this reduce hallucinations?

It includes instructions discouraging confident claims about uncertain information and excessive dependence on past answers, but improvement has not been validated. It does not guarantee greater accuracy or safety.

Where can I report feedback or problems?

Use GitHub Issues. Include reproduction conditions, expected results, and actual results. Do not post personal information, confidential information, or credentials.
